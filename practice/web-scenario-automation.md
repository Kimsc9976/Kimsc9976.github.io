## 문제

비즈하우스는 인쇄 상품군이 많은 커머스 플랫폼이라, 상품군이 늘수록 확인해야 할 사용자 흐름도 늘었습니다.

- 기능 하나하나가 동작해도, 사용자가 주문 완료까지 도달하는지는 따로 확인해야 했습니다.
- 배포 후 운영 환경에서 생기는 흐름 이상은 QA가 볼 수 없는 구간이었습니다.
- UI/UX 개선안이 실제로 나은지 판단할 근거가 부족했습니다.

## 한 일

### 1. 행동 데이터에서 시나리오 도출

- 사용자 행동 데이터를 분석해 많이 쓰이는 흐름을 핵심 유저 시나리오로 정의
- 시나리오를 제품군 단위로 묶어, 상품군이 늘어도 같은 구조로 추가할 수 있게 설계

### 2. Playwright 시나리오 자동화

- 핵심 시나리오를 Playwright로 자동화해 릴리즈마다 회귀 검증
- 행동 데이터를 근거로 어떤 흐름부터 자동화할지 우선순위 결정

### 3. Checkly 운영 모니터링

- 핵심 흐름을 운영 환경에서 주기적으로 실행해 배포 후 이상을 바로 감지
- QA 범위를 릴리즈 전 검증에서 배포 후 운영까지 확장

### 4. A/B 테스트와 Usability Test

- UI/UX 개선안에 대한 A/B 테스트 설계와 결과 검증
- 실제 사용자 경험을 기준으로 Usability Test 수행, 개선 판단 근거로 정리
